# Q-MECH: A GPU-Accelerated Open-Source Python Pipeline for Quantum Mechanical (DFT & QM/MM) Analysis of Molecular Mechanism of Inhibition in Protein–Ligand Complexes
GPU-accelerated DFT/QM-MM pipeline for molecular mechanism of inhibition analysis of protein-ligand complexes using PySCF, B3LYP/def2-SVP, real Fukui indices, MEP from electron density, and electrostatic embedding
